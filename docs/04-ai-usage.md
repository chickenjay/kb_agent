# AI 辅助使用与个人贡献

本仓库主体实现由 Codex 在本次对话中生成，包括需求整理、技术方案、Python/JavaScript 代码、合成资料、测试和文档。用户明确选择了 Python + LangGraph、兼容模型接口、原生 HTML/JavaScript + Tailwind、实时执行进度，并授权实现。

AI 实际完成：

- 构建 LangGraph 决策循环、模型 HTTP 适配、检索/读取工具、引用和状态校验。
- 构建 FastAPI SSE 和前端页面、流解析器、取消与导出。
- 编写并运行离线评估与自动测试，保存实际输出和 Trace。
- 通过浏览器验证冲突、追问、原文展开、停止与响应式布局。
- 查阅框架及 Tailwind 官方资料，处理依赖安装和中文目录导入问题。

未由 AI 完成或不能代填：

- 候选人的独立代码修改、对架构取舍的个人理解、手动复核和实际投入时间，尚无本人记录。
- 候选人亲自执行、人工语义核验和独立复现，尚无本人记录。后续用户授权的 DeepSeek 实测由 AI 执行，不是候选人个人手工完成。
- GitHub 创建、评审授权、最终提交与 SHA。

候选人提交前应补充自己实际修改的文件、修改原因、验证命令及结果；若没有独立修改，应据实说明。不得把 AI 生成内容全部描述为个人原创，也不得把 Mock 结果写成真实模型效果。

AI 执行墙钟时间由 verification 的 timing.json 记录；它不是候选人的个人工时。依赖及运行记录均为实际执行所得，不包含真实密钥或员工隐私数据。
