# AI 辅助使用与个人贡献

题号：3，企业知识问答 Agent。

## AI 辅助内容

AI 辅助用于代码生成与测试。代码生成覆盖 Agent 决策循环、检索与片段读取工具、模型接入、引用校验、后端接口和 Web 页面；测试覆盖用例构造、自动测试、离线 Mock、真实模型调用及运行记录整理。

## 个人修改

个人修改为修正技术方案，包括技术选型、交付范围以及前后端交互方案的调整。根据考核要求确定 Python + LangGraph、兼容模型接口、原生 HTML/JavaScript + Tailwind CSS 与实时执行进度的组合，并将重点放在引用核验、冲突处理和可复现验证上。

## 验证结果与用时

80 项 Python 测试和 14 项前端测试通过；Mock 20/20，指定 DeepSeek 模型完整回归 20/20 通过自动检查。真实首轮 17/20、定向复测 3/3 的记录同时保留，详见 [评估报告](03-evaluation.md)。

项目累计墙钟用时约 1 小时 35 分钟，统计截至 2026-10-28 13:34:02（UTC+8）；其中首个可提交版本用时为 1 小时 22 分钟。起止依据为执行记录与首个 Git 提交，详见 [用时统计](../examples/verification/project-time.json)。墙钟时间包含工具执行、交互及必要等待，不是单独测量的个人手工工时。

Mock 只验证流程；自动引用检查不等于任意答案的语义支持已被证明。AI 辅助阅读记录与候选人本人复核分开保存。真实密钥仅存于本机被 Git 忽略的配置，未进入提交材料。
